# WebOpener · 定时打开网页

在**语文课前 X 分钟**（科目与提前量可配）或**每周固定时间**自动打开指定网页；
打开前 1 分钟弹出**独立确认对话框**，点击「暂不打开」可取消本次计划，超时未操作则照常打开。

## 规则类型

| 类型 | 说明 |
| --- | --- |
| 课前打开 | 科目名匹配（如「语文」）时，课前 X 分钟打开（默认 1 分钟）；提醒在打开前 1 分钟（默认课前 2 分钟）弹出 |
| 每周定时 | 每周 X 的 HH:mm 打开；提醒在同一时刻前 1 分钟弹出 |

## 安装

软件内「设置 → 插件 → 从本地安装」选择 `cipx/WebOpener.cipx`，重启生效。

## 配置位置

`{安装目录}/Config/Plugins/WebOpener/rules.json`

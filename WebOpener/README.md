# WebOpener · 定时打开网页 / 文件

在**语文课前 X 分钟**（科目与提前量可配）或**每周固定时间**自动打开指定目标；
打开前 1 分钟弹出**独立确认对话框**，点击「暂不打开」可取消本次计划，超时未操作则照常打开。

## 规则类型

| 类型 | 说明 |
| --- | --- |
| 课前打开 | 科目名匹配（如「语文」）时，课前 X 分钟打开（默认 1 分钟）；提醒在打开前 1 分钟（默认课前 2 分钟）弹出 |
| 每周定时 | 每周 X 的 HH:mm 打开；提醒在同一时刻前 1 分钟弹出 |

## 打开对象

| 类型 | 说明 |
| --- | --- |
| 网页 | 以 `http://` / `https://` 开头的网址，用默认浏览器打开 |
| 本地文件 | 任意本地文件（文档、程序等），用系统默认程序打开 |
| 图片 | 本地图片（jpg / png / bmp / gif / webp 等）勾选「图片全屏显示」后，用插件内置的**置顶全屏窗口**显示；可设置显示时长（秒），0 表示不自动关闭；点击或按 Esc 立即关闭 |

## 全局静默时段

在设置页可配置若干**全局静默时段**（如 `12:00 – 13:30`，支持跨零点 `23:00 – 06:00`）。
命中静默时段时，所有**「课前打开」**计划既不弹出提醒、也不打开目标（「每周定时」计划不受影响）。

## 安装

软件内「设置 → 插件 → 从本地安装」选择 `cipx/WebOpener.cipx`，重启生效。

## 配置位置

`{安装目录}/Config/Plugins/WebOpener/rules.json`

> 从 1.0 升级时旧格式（纯规则数组）会被自动识别并迁移，无需手工处理。

01值日生提醒 插件

在每节上课前的时间点或自定义时间点，提醒值日生擦黑板 / 值日。 支持自定义提醒时间与提醒内容，并提供预设内容。

需求拆解

  • 提醒时间：每节上课前 X 分钟（X 可配，默认 2 分钟）
  • 自定义时间：每日固定时刻 / 每周几固定时刻，可多条
  • 提醒内容：每条规则独立文案，支持通知显示 + 语音播报
  • 预设内容：内置模板「请值日生擦黑板」「请值日生整理讲台」「请值日生倒垃圾、关灯」一键套用

设计要点

  • 工程骨架照抄 ClassIsland.ExamplePlugin：目标框架 net6.0-windows7.0，引用本仓库 ClassIsland.PluginSdk（Private=false），CreateCipx=true 构建即出包。
  • 调度：注入 ILessonsService，定时器轮询「下节课开课时间 − X 分钟」，课表中途调整也能跟上；自定义时间用每日/每周定时器。
  • 展示：调用 INotificationHostService.ShowNotification，语音走现有 ISpeechService 通道。
  • 设置页：插件自带 SettingsPage，规则列表 + 预设模板下拉。
构建产出 DutyReminder.cipx → 软件内「从本地安装」 → 落盘 D 盘 Plugins\ → 重启生效（配置存 D 盘 Config\）

02定时打开网页 插件

语文课前 1 分钟与周日自定义时间打开固定网页；打开前 1 分钟（即课前 2 分钟） 弹出独立确认对话框，点击「暂不打开」即可取消本次计划。

课前 2 分钟（＝打开前 1 分钟）

弹出独立确认对话框：「即将打开 ××网页」，带 暂不打开 / 关闭按钮，置于主窗口之上。

点击取消 / 关闭对话框

置位取消标志，本次计划作废，到点不再打开；对话框超时未操作则视为确认。

课前 1 分钟（打开动作时刻）

未取消则 Process.Start(URL)（ShellExecute，同内置「运行」行动的网页分支写法）。

规则类型

  • 类型 A · 语文课前：科目名匹配「语文」，课前 X 分钟打开（默认 1）；提醒固定在打开前 1 分钟（默认课前 2 分钟）弹出，按课表自动跟随
  • 类型 B · 每周日：自定义时刻（可多条），不依赖课表
  • 每条规则独立配置目标 URL，可启停

选型依据：现有自动化缺两块原语——触发器没有「课前提前量」，通知没有按钮交互， 因此纯配置拼不出「可取消」，必须由插件自调度。

实现要点

  • 调度：注入 ILessonsService 轮询判断「下节课科目 + 距开课倒计时」；周日规则用定时器。
  • 弹窗：独立确认对话框——插件自建 WPF Window（Topmost、置于主窗口之上），确认通道不走通知系统。
  • 打开：ShellExecute 方式打开 URL，兼容 Win7 默认浏览器。

已确认（决策定稿）

  1. 「语文课前 1 分钟」指打开动作发生在课前 1 分钟；提醒则在课前 2 分钟（即打开前 1 分钟）弹出。
  2. 弹窗形态：独立确认对话框（插件自建 WPF Window），不使用通知横幅内嵌按钮。

03天气提醒 脚本更新

自定义时间 / 课间的天气预报提醒用现有功能配置即可； 逐小时预报 6h → 12h 是主程序两处硬编码，用补丁脚本原地更新，不做完整重装。

① 自定义时间提醒 —— 纯配置，零代码

  • 课表时间点挂行动「显示天气提醒」（classisland.notification.weather），到点即弹。
  • 或用自动化：触发器「课间休息时 / cron 定时」+ 同一行动，任意课间、任意时刻可配。

② 6h → 12h —— 脚本更新的唯一改动点

  • WeatherHourlyForecastNotificationProvider.xaml.cs:35
    for (i = 0; i < 6; i++) → < 12
  • WeatherHourlyForecastNotificationProvider.xaml
    手写 6 组时间/图标/温度 → 建议改为 ItemsControl 动态生成 12 组

补丁脚本更新流程（patch.ps1）

前置验证：小米天气接口 forecastHourly ≥ 12 条 → 改两处硬编码 → dotnet publish 同配置出包 → 脚本：停 ClassIsland 进程 → 备份原文件 → D 盘同路径、同文件名原地覆盖 → 启动

风险与对策：程序运行中文件被占用 → 脚本先停进程；还原系统 → 改动全在 D 盘，还原不回滚； 自启 → C 盘快照里的快捷方式指向 D 盘路径不变，无需任何操作。

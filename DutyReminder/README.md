# DutyReminder · 值日生提醒

在每节上课前的时间点或自定义时间点提醒值日生擦黑板 / 值日。

## 功能

- **每节上课前**：按课表自动跟随，提前 X 分钟（默认 2 分钟）提醒，每节课只提醒一次。
- **每天 / 每周固定时间**：自定义 `HH:mm` 时间点，可多条规则。
- **自定义内容**：每条规则独立文案，内置预设模板（擦黑板、整理讲台、倒垃圾等）一键套用。
- **语音播报**：可按规则开关，走宿主配置的语音服务（如 MiMoTTS）。

## 安装

通过软件内「设置 → 插件 → 从本地安装」选择 `cipx/DutyReminder.cipx` 安装，重启生效。

## 配置位置

规则保存在 `{安装目录}/Config/Plugins/DutyReminder/rules.json`。

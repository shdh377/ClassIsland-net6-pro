# DutyReminder · 值日生提醒

在每节上课前的时间点或自定义时间点提醒值日生擦黑板 / 值日，并可按每周 / 每日自动轮换值日小组。

## 功能

- **每节上课前**：按课表自动跟随，提前 X 分钟（默认 2 分钟）提醒，每节课只提醒一次。
- **每天 / 每周固定时间**：自定义 `HH:mm` 时间点，可多条规则。
- **自定义内容**：每条规则独立文案，内置预设模板（擦黑板、整理讲台、倒垃圾等）一键套用。
- **语音播报**：可按规则开关，走宿主配置的语音服务（如 MiMoTTS）。
- **值日小组自动轮换**：见下节。

## 值日小组自动轮换

在「设置 → 插件 → 值日小组轮换」页中：

1. **上传值日生表**：可直接在文本框填写，或「从文件导入…」选择 `.txt` / `.csv`
   （兼容 UTF-8 与中文系统 Excel 导出的 GB2312/GB18030 编码）。
   每行一组，格式如下：

   ```
   第一组：张三、李四、王五
   第二组：赵六, 钱七 孙八
   张三 李四 王五
   ```

   - 组名可省略，省略时自动命名为「第 N 组」；
   - 组员之间用逗号、顿号、分号或空格分隔；
   - 以 `#` 开头的行、含「组员 / 成员 / 名单」的表头行会被忽略。

2. **配置轮换**：
   - 轮换周期：每周一组 / 每组一天；
   - 提醒星期（仅每周轮换）与提醒时间 `HH:mm`；
   - **轮换基准日期**：该日期所在的周期视为「基准组」；每周轮换按自然周（周一为一周之始）对齐；
   - **基准组序号**：基准日期对应第几组（从 1 开始）；
   - **提醒文案模板**：占位符 `{group}` 组名、`{members}` 组员名单、`{index}` 组序号，
     例如 `本周值日小组：{group}（{members}）`。

3. 到提醒时刻后，插件会**列出新一组组员名单**并弹提醒（可选语音播报），同时写入**轮换记录**。
   「轮换记录」列表可查看历史，并可一键清空。

## 安装

通过软件内「设置 → 插件 → 从本地安装」选择 `cipx/DutyReminder.cipx` 安装，重启生效。

## 配置位置

规则、值日生表、轮换设置与轮换记录都保存在 `{安装目录}/Config/Plugins/DutyReminder/rules.json`。

> 从 1.0 升级时旧格式（纯规则数组）会被自动识别并迁移，无需手工处理。
